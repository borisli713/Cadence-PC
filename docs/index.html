WORKFORCE ARCHITECTURE

Designed for desktop dispatchers and shift teams.

Every scheduling decision, shift verification workflow, and desktop integration runs in compiled Rust with direct sync to your team's Cadence workspace.

01

Fairness Allocation Engine

Automatically distributes open and recurring shifts using weekly hour targets, overnight rollover calculations, rest-window checks, and approved time-off exclusions computed natively in Rust.

02

Verified Shift Reports & Approvals

Log actual start, end, and break minutes against assigned shifts. Managers approve claims, swaps, and time-off requests individually or in audited batches.

03

Native Windows Integration

Supports external-browser Google Sign-In with deep-link handoff back to the desktop window, tray alerts for incoming updates, and automatic Windows release checks.

04

Standard Calendar & Payroll Exports

Generate compliant .ics calendar feeds with clean overnight shift rollover alongside RFC 4180 CSV shift reports for payroll and audit archiving.
